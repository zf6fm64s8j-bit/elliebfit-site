# Repository Instructions

This public static site is deployed from GitHub. Preserve the hand-edited `index.html`; do not
replace it with a fresh export.

- Work from current `origin/main` on a focused branch and keep private client or business data out
  of Git.
- Validate HTML, internal links, mobile behavior, accessibility, forms, and the deployment workflow
  before publication.
- Treat a successful build or Pages job separately from a rendered-site readback.
- Preserve existing redirects, analytics consent behavior, and the escaped embedded JSON boundary.
- Use a pull request for public content, form, analytics, accessibility, or deployment changes.
